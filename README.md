# Personal Finance Manager

A Java project built step-by-step while learning Java programming and software development.

## Project Goal

Build a Personal Finance Manager application that allows users to:

- Track income
- Track expenses
- Categorize transactions
- View reports
- Manage budgets

## Current Features

- Display application title
- Store values using variables
- Read user input with Scanner
